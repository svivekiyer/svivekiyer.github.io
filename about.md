I work on enterprise storage and backup infrastructure — SAN fabrics, filesystems, array fleets, and the automation that keeps them honest.

Most of what I find interesting sits in the gap between what a vendor tool reports and what an engineer actually needs to know at the moment they need to know it. That gap is where almost everything on this site comes from.

The writing here is paired with code wherever the code can be made public. Where it cannot, I rebuild the pattern from scratch against synthetic data and write about that instead.
